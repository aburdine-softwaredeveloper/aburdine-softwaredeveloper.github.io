About

I'm a full-stack developer with five years of professional experience building and maintaining enterprise applications, all of it for Missouri state government. Most of that work lives in C#, .NET, ASP.NET, and SQL, managed through Azure DevOps and Git-based workflows, with the kind of security and data-integrity requirements that come with handling the public's records.

Recently I shipped a secure web application that digitized applicant information processing, replacing a slower manual workflow. I also lead our team stand-ups and act as the person other developers come to when a shared program breaks.

Outside the Microsoft stack, I built Mournvale — a multiplayer text-based game with a Node and TypeScript server, a framework-free client, and a deploy pipeline I wired up myself. It was a way to get real production experience in modern JavaScript tooling, and it's how I tend to learn a new language: pick something with enough moving parts that shortcuts stop working.

I hold two bachelor's degrees: Software Development from Western Governors University and Social Work from Evangel University. The second one is not decoration. Government software gets used by people in the middle of something stressful — a certification they need, a background check standing between them and a job — and knowing how to sit with that changes the questions I ask before I write anything.

Work

  • Mournvale — multiplayer text world

    A grim-gothic village you explore by typing. The server is authoritative: it owns every piece of game state and streams lean view snapshots to clients over WebSocket, while the client is vanilla TypeScript and DOM with no framework. Saves are versioned JSON with a real migration path, so a character created on an old build still loads cleanly on a new one.

    Pushing to main auto-deploys to a VPS through GitHub Actions, running under PM2 or Docker. Built with an AI-assisted workflow, which means I can talk concretely about where that helps and where it quietly makes things worse.

    TypeScript, Node.js, Vite, WebSocket, GitHub Actions, Docker, PM2

    Mournvale on GitHub

  • Criminal background check processor

    A C# application that streamlines the processing of criminal background checks, so providers working with vulnerable populations can be cleared without a slow manual review. Better accuracy and higher throughput than the process it replaced, on a workflow where a missed disqualifying history is the failure that actually matters.

    C#, .NET, compliance workflows

  • Teacher certification web applications

    Maintained and enhanced the web applications behind teacher certificate issuance and core educator data management for the state. The work was reliability and data integrity: administrators and applicants statewide depend on these records being right, and on the system being available when a certification deadline is close.

    C#, ASP.NET, SQL, Bootstrap, Azure DevOps

  • Mental health billing audit

    Advanced Excel diagnostics built for a behavioral health non-profit to separate billable from non-billable medically necessary services. It surfaced billing discrepancies, recovered organizational funds, and left guardrails behind to prevent fraud going forward.

    Excel, data analysis, healthcare non-profit

  • Nautical — mobile app

    My senior capstone: a mobile application taken from concept through UI/UX design, application architecture, and a versioned release. The closest thing in my history to owning a product end to end alone.

    Java, mobile UI/UX, capstone

    Nautical v1.1 on GitHub
